# 老式电视机原理可视化

一个基于 Three.js 的 CRT 老式电视机工作原理可视化项目，展示从天线接收信号到屏幕成像的过程。

## 功能

- Three.js 建模老式 CRT 电视机、天线、显像管、电子枪、偏转线圈和荧光屏。
- 信号链路演示：RF 载波、解调视频、同步脉冲、当前扫描线和屏幕画面预览。
- 电子束逐点扫描，亮度信号实时控制屏幕亮暗。
- 可切换整体、剖视、信号、屏幕观察模式。
- 支持调节扫描速度、亮度和信号噪声。

## 运行

```bash
npm install
npm run dev
```

默认本地地址：

```text
http://127.0.0.1:5173
```

## 构建

```bash
npm run build
```
