# 老式电视机原理可视化

一个基于 Three.js 的 CRT 老式电视机工作原理可视化项目，展示从天线接收信号到屏幕成像的过程。

## 功能

- Three.js 程序化建模一台 1980 年代风格的 35 cm 黑白电视机：
  - 胡桃木贴皮机箱、塑料面框、拉丝铝控制面板（滚花旋钮、频道刻度、电源指示灯、冲孔喇叭网）、锥形散热后盖与警告贴纸、木腿、拉杆天线与 300Ω 扁馈线；
  - 显像管：球面玻屏、超椭圆屏裙、石墨涂层锥体、防爆箍、阳极帽与高压线、透明管颈内的电子枪（灯丝、阴极、G1~G4、玻璃支撑杆、芯柱引脚、管座板）；
  - 偏转线圈：鞍形行线圈、铁氧体磁环、环形场线圈、紧固卡箍、中心调节磁环；
  - 机芯：酚醛电路板及数百个实例化元件、行输出变压器、电源变压器、散热片、中周、高频调谐器、线束。
- 象限剖切：一键切开外壳、后盖、显像管与偏转线圈，截面以实心颜色呈现，可直接看到电子束在管内偏转。
- 物理材质 + 环境反射 + 软阴影 + 泛光，屏幕作为面光源照亮周围；鼠标悬停显示部件说明。
- 信号链路演示：RF 载波、解调视频、同步脉冲、当前扫描线和屏幕画面预览。
- 电子束逐点扫描，亮度信号实时控制屏幕亮暗。
- 可切换整体、剖视、信号、屏幕观察模式。
- 支持调节扫描速度、亮度和信号噪声。

## 运行

```bash
npm install
npm run dev
```

默认本地地址：

```text
http://127.0.0.1:5173
```

## 构建

```bash
npm run build
```
